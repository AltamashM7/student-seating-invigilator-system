# S2 Account Rules

## Password policy
- Minimum 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one digit

## Onboarding
1. The seeded administrator logs in.
2. An administrator creates additional admin or faculty accounts.
3. Faculty receives a username and initial password.
4. The user logs in and can use reset-password when the registered username/email match.

## Validation
- Username, name, role and email are required.
- Email must use a basic valid email format.
- Faculty accounts require an employee code.
- Username, email and employee code must be unique where applicable.
- Backend validation is authoritative even if the browser has already validated the form.
