# Defect Severity

| Severity | Meaning | Example |
|---|---|---|
| Critical | Main workflow cannot continue or data is badly corrupted | Login unavailable for every user |
| High | Major feature fails with no practical workaround | Room conflict is not detected |
| Medium | Feature partly works or has a workaround | One CSV error message is unclear |
| Low | Cosmetic or minor usability problem | Alignment issue in a form |
