User guide

Academic administration, examination seating, invigilation and reports are available in this browser version. Sample records and practice changes belong to this browser.

Sign in

Staff login: administrator admin / Admin@123; faculty cse.faculty1 / Faculty@123. Students use the public portal without signing in.

Academic records and seating

  1. Search CSE26Y1A001 in the student portal and open the timetable. Only published exams appear.
  2. Sign in as administrator. Academic years, departments, divisions, students, courses and enrollments can be managed from the navigation. Dashboard counts use FY, SY, TY and BE.
  3. Add or edit a room or course. Referenced records are protected. A new room creates seats automatically; mark suitable seats using its accessibility controls.
  4. Open CSV Import, download the sample and import it. Its 24 rows add 12 students, each enrolled in two workshop courses. Re-import reports duplicates.
  5. Create a draft examination using a workshop course such as CSE103 and a new room. Choose dates/times that avoid clashes, then generate seating.
  6. On Seating, choose CSE102. Move a student to an empty odd-column seat or swap two eligible occupied seats. Enter a reason, review and confirm. Change history records the action.
  7. Regeneration preserves manual seats by default. Replacing them requires the advanced option and acknowledgement. Accommodation requirements can be reviewed and changed when every affected plan has sufficient suitable seating.

Invigilation and faculty duties

  1. Open Faculty Availability. Select a faculty member to set eligibility, unavailable periods and workload limits. Teaching/course conflicts and global rest/staffing rules are also available.
  2. Open Invigilation, choose an academic year and exam, and select Review duty allocation. Complete seating is required first. Enter a reason and confirm the proposed plan.
  3. Accepted and manual duties are kept during normal regeneration. The advanced replacement option requires explicit acknowledgement.
  4. Publish the exam from Exams. Sign in as an assigned faculty member to see the room details and accept or decline a scheduled duty. A decline requires a reason.
  5. Return as administrator to reassign a declined duty. Select the replacement faculty member, review the change and confirm.
  6. Open Conflicts & Readiness to review timetable, seating and invigilation issues. Follow the Review links to address missing seating, uncovered duties or pending confirmations.

Reports and notifications

Reports provides room-wise seating, student-wise seating, faculty duty lists and the examination schedule as PDF or CSV. Faculty can download their own duty list from their schedule.

Notifications contains assignment updates and duty responses, with read/unread controls. This browser version stores notices locally. Real email delivery is available in the Java application after SMTP configuration.

Sample data

Reset sample data restores the original 240 fictional students, 480 enrollments, 24 exams, seating and accounts. It also clears practice duties and notifications. Existing browser data is otherwise retained when the website is updated.

About this version

Accounts and data operations run in JavaScript for this familiarization copy. Use fictional records and demo passwords. Changes stay in the current browser and are not shared with other members. Clearing browser storage removes practice changes.

The complete Java Servlet, JDBC, MySQL and Tomcat project is available in the GitHub repository. Its backend transactions and SMTP delivery run in that application. Publication of this copy does not claim new KPI or workflow test results.
