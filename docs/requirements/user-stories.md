# S1 User Stories

## Administrator
- As an administrator, I want to log in so that I can manage examination data.
- As an administrator, I want to create faculty accounts so that faculty can access the system.
- As an administrator, I want to manage rooms and courses so that examination data remains organized.
- As an administrator, I want to import student records from CSV so that bulk data entry is faster.
- As an administrator, I want to create exams and see conflicts before saving them.

## Faculty
- As a faculty member, I want to log in so that I can view examination information available to me.
- As a faculty member, I want to view the examination timetable.

## Student
- As a student, I want to view the examination timetable.
- As a student, I will later search my room and seat after the seating module is implemented.
