User guide

The sample records and practice changes belong to this browser. No installation is required.

Sign in

Staff login: administrator admin / Admin@123; faculty cse.faculty1 / Faculty@123. Students use the public portal without signing in.

Try the main workflows

  1. Search CSE26Y1A001 in the student portal and open the timetable. Only published exams appear.
  2. Sign in as administrator. Explore academic years, departments, divisions, students, courses and enrollments. The dashboard shows FY, SY, TY and BE counts.
  3. Add a new room or course and edit it. Records used by existing exams are protected. Each new room creates seats automatically; use its accessibility controls to mark suitable seats.
  4. Open CSV Import, download the sample and import it. It adds 12 students and 24 enrollments. Re-import reports 24 duplicates.
  5. Create a draft examination using a workshop course such as CSE103 and a new room. Select dates/times that avoid clashes, then generate seating.
  6. On Seating, choose CSE102. Try a manual move to an empty odd-column seat, or swap two eligible occupied seats. Enter a reason and confirm. Check Change history.
  7. Regenerate: manual seats are preserved by default. The advanced replacement option requires another acknowledgement. Cancel a preview to keep the plan unchanged.
  8. Try Accommodation requirements. Adding a third requirement to CSE102 fails because its spaced layout has only two eligible accessible seats. A newly created accessible room can support additional requirements in your own exam.
  9. Use Reset sample data to restore the initial 240 students, 24 exams, seating and demo accounts.

About this version

Login, data management and seating rules run in JavaScript for this training copy. Login is simulated; use fictional data and demo passwords. Changes are saved locally and are not shared with other members. Clearing browser storage removes practice changes.

The original application uses Java Servlets, JDBC, MySQL and Tomcat. Its backend security, transactions and KPI testing belong to that application. Invigilator allocation is planned and is not available in either current version.
