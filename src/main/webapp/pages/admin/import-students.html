File format and import rules

Download format template

One row per student/course enrollment. Reimporting the sample reports duplicates. Use unpublished courses without generated seating for new enrollments.

roll_number,name,email,department_code,semester,course_code,academic_year,division,requires_accessible

Requires accessible: true or false. Plain comma-separated fields only; quoted commas are unsupported. Academic year, division and course offering must already exist.
