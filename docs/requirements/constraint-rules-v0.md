# Constraint Rules v0

## Seating rules reserved for later sprint
- A room cannot receive more students than its capacity.
- Seat numbers must be unique inside one room.
- A student must not receive two seats for the same examination.

## Invigilation rules reserved for later sprint
- One faculty member cannot be assigned to two rooms at the same time.
- Faculty workload should be kept reasonably balanced.

## S4 timetable rules
- End time must be later than start time.
- A room cannot be used by overlapping examinations.
- A student enrolled in two courses cannot have overlapping examinations for those courses.
- Cancelled examinations do not create timetable conflicts.
